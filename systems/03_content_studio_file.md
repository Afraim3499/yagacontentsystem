# File Three: Yaga Content Studio File

The Yaga Content Studio is the owner's daily working file. It is designed to be streamlined so that the owner rarely needs to open the Master File during routine content operations.

---

## 1. Tab Layout & Controls

### Visible Tabs
- **Dashboard**
- **Daily Template**
- **Date Tabs** (e.g. `2026-07-31`)
- **Content Archive**

### Buttons & Controls
- `Add New Day`
- `Validate Day`
- `Send to Team`
- `View Distribution`
- `Cancel Unsent Day`

*Mobile Compatibility: To guarantee reliable execution on mobile devices, all button controls must also be accessible as dropdown actions or checkboxes on the Dashboard tab.*

---

## 2. Daily Content Tab Schema

### Header Section
- Date
- Day status (`Draft`, `Ready`, `Sent`, `Completed`, `Cancelled`)
- Base content count
- Total creator assignments
- Text assignment count
- Image-backed assignment count
- Article assignment count
- Missing creator content count
- Distribution status

### Main Content Table Structure

| Platform | Content Type | Slot | Publish Time | Shared Topic | Creator 1 Content | Creator 2 Content | Creator 3 Content | Drive Link | Notes |
|---|---|---|---|---|---|---|---|---|---|

### Content Types Dropdown Options
- Text Post
- Image Post
- Article
- Thread
- Carousel
- Telegram Post
- Story
