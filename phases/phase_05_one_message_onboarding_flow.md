# Phase 05 — One-Message Onboarding Flow

## 1. Objective & Scope
Build the 1-message platform instruction generator, minimal credential collection handler, and setup confirmation flow.

---

## 2. Action Items
- Build instruction compiler pulling display names, handles, bios, images, links, follow rules, and intro posts.
- Deliver single composite setup message via Telegram bot.
- Implement 4-step minimal credential prompt flow (Login identifier, password, public username, conditional security key).
- Build setup confirmation dialogue handler (**[Confirm Setup Complete]**).

---

## 3. Completion Requirement
An employee can complete an assigned platform setup entirely through Telegram without opening a spreadsheet.
