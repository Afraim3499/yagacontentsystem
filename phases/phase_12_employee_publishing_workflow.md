# Phase 12 — Employee Publishing Workflow

## 1. Objective & Scope
Deploy employee daily work interfaces, task viewing tools, link submission flows, and real-time completion tracking.

---

## 2. Action Items
- Build Daily Work Summary Telegram view.
- Build individual task cards (Caption, media attachments, specific instructions).
- Build **[Mark as Posted]** button & link collection flow.
- Record submitted URLs into `Submissions` table.
- Build **[Report a Problem]** issue collection handler.

---

## 3. Completion Requirement
Employees complete 100% of daily publishing operations through Telegram.
